Problem

application interface가 source capability, 화면 이름, binary 이름과 호출 순서 제약을 caller에게 노출한다.

Solution

source와 등록 정보는 implementation 안에 두고 선택·검증·병렬 조회를 한 interface 뒤로 모은다.

Wins

  • interface surface shrinks
  • no execution capability leak
  • tests need no fake source
  • leverage across all modes
UsageSource seam 자체는 진짜다: Claude, Codex, test adapter가 실제로 교체된다. 후보는 seam 제거가 아니라 interface deepening이다.

  • memory adapter tests behavior
  • file tests only encoding
